# 打包与发布说明（Electron）

本说明覆盖 Electron 桌面应用的构建与发布流程，产物通过 GitHub Releases 分发并支持自动更新。

## 依赖

- Node.js >= 18
- macOS 打包：Xcode Command Line Tools
- Windows 打包：Visual Studio Build Tools

## 本地构建

```bash
cd frontend
npm install
npm run build:electron
```

构建产物目录：`frontend/release/`

## 发布到 GitHub Releases（自动更新）

`electron-builder` 已在 `frontend/package.json` 中配置 `publish` 指向 GitHub Releases。发布时需要设置 token：

- `GH_TOKEN` 或 `GITHUB_TOKEN`

示例：

```bash
cd frontend
GH_TOKEN=your_token npm run build:electron -- --publish always
```

## 常见问题

- 构建失败：确认 Node 版本、系统编译工具链已安装。
- 自动更新不可用：检查 GitHub Releases 是否生成以及 `publish` 配置是否正确。
